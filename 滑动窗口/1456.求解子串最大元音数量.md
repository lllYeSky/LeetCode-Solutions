# [1456.求解子串最大元音数量](https://leetcode.cn/problems/maximum-number-of-vowels-in-a-substring-of-given-length/solutions/2809359/tao-lu-jiao-ni-jie-jue-ding-chang-hua-ch-fzfo/)

## 题目

给你一个字符串**s**，计算所有长度**恰好**为 *k* 的子串中，最多可以包含多少个元音字母。

## 思路

子串**长度固定**，那么可以将一个子串类似成一个*窗口*

我们用*窗口*去遍历字符串，左端点为*i*，右端点就为*i+k-1*

代码如下：

~~~ c++
class Solution {
public:
    int maxVowels(string s, int k) {
		int ans = 0, t = 0; //t暂存元音数目
    	for (int i = 0; i < s.size(); i++){
    		if (s[i] == 'a' || s[i] == 'e' ||
            	s[i] == 'i' || s[i] == 'o' || s[i] == 'u'){
        		t++;
    		}
        	int l = i - k + 1; 
        	//用左端点方便点，l<0直接跳，用右端点的话还需考虑最前面的k子串
        	if(l < 0){
            	continue;
        	}
        	ans = max(ans, t);
        	if (s[l] == 'a' || s[l] == 'e' ||
            	s[l] == 'i' || s[l] == 'o' || s[l] == 'u'){
        		t--;
    		}
        }
        return ans;
    }
};
~~~

## 复杂度分析

- 时间复杂度：O(n)，其中 n 是 s 的长度。
- 空间复杂度：O(1)。
