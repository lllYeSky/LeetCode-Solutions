# [1461.检查一个字符串是否包含所有长度为K的二进制子串](https://leetcode.cn/problems/check-if-a-string-contains-all-binary-codes-of-size-k/description/)

## 题目

给你一个二进制字符串 `s` 和一个整数 `k` 。如果所有长度为 `k` 的二进制字符串都是 `s` 的子串，请返回 `true` ，否则请返回 `false` 。



## 思路

当时写的时候没想出来，直接看*灵神*吧

> *灵神*给了两种

### 方法一：暴力

暴力枚举所有长为 `k` 的子串，保存到一个哈希集合中。

如果最终哈希集合的大小恰好等于 `2k`，那么说明**所有**长为 `k` 的二进制串都在 `s` 中。

(我似乎忘了有**unset**和**string**的组合......)

~~~c++
class Solution {
public:
    bool hasAllCodes(string s, int k) {
        unordered_set<string> st;
        for (int i = k; i <= s.size(); i++) {
            st.insert(s.substr(i - k, k));
        }
        return st.size() == (1 << k);
    }
};

作者：灵茶山艾府
~~~

#### 复杂度分析

- 时间复杂度：O((*n*−*k*)*k*)，其中 *n* 是 *s* 的长度。
- 空间复杂度：O((*n*−*k*)*k*)。

### 方法二：位运算滑窗

把子串转成整数，保存到哈希集合或者布尔数组中。

**小优化**：如果循环过程中发现已经找到 `2k` 个不同的二进制数，可以提前返回 `true`。

~~~c++
class Solution {
public:
    bool hasAllCodes(string s, int k) {
        const int MASK = (1 << k) - 1;
        vector<int8_t> has(1 << k);
        int cnt = 0; 
        int x = 0;
        for (int i = 0; i < s.size() && cnt < (1 << k); i++) {
            // &:同1则1，|:有1则1
            // MASK应该为011111111......
            // &MASK 目的是去掉超出 k 的比特位
            // (s[i] & 1):把字符0和1改为二进制
            // 把 s[i] 加到 x 的末尾：x 整体左移一位，然后或上 s[i]&1
            x = (x << 1 & MASK) | (s[i] & 1);
            if (i >= k - 1 && !has[x]) {
                has[x] = true;
                cnt++;
            }
        }
        return cnt == (1 << k);
    }
};

作者：灵茶山艾府
~~~

#### 复杂度分析

- 时间复杂度：O(*n*)，其中 *n* 是 *s* 的长度。
- 空间复杂度：O(*n*−*k*) 或 O(2*k*)，取决于实现。
