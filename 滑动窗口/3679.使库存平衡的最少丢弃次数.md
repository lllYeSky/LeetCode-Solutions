# [3679.使库存平衡的最少丢弃次数](https://leetcode.cn/problems/minimum-discards-to-balance-inventory/submissions/725718233/)

## 题目

给你两个整数 `w` 和 `m`，以及一个整数数组 `arrivals`，其中 `arrivals[i]` 表示第 `i` 天到达的物品类型（天数从 **1 开始编号**）。

物品的管理遵循以下规则：

- 每个到达的物品可以被 **保留** 或 **丢弃** ，物品只能在到达当天被丢弃。

- 对于每一天 `i`，考虑天数范围为第 `i` 天前的 `w` 天
	- 每种物品（即数字）最多出现`m`次
	- 超过的话就**丢弃**

返回为满足每个 `w` 天的窗口中每种类型最多出现 `m` 次，**最少** 需要丢弃的物品数量。



**示例 1：**

**输入：** arrivals = [1,2,3,3,3,4], w = 3, m = 2

**输出：** 1

**解释：**

- 第 1 天，物品 1 到达。我们保留它。
- 第 2 天，物品 2 到达，窗口 `[1, 2]` 是可以的。
- 第 3 天，物品 3 到达，窗口 `[1, 2, 3]` 中物品 3 出现一次。
- 第 4 天，物品 3 到达，窗口 `[2, 3, 3]` 中物品 3 出现两次，允许。
- 第 5 天，物品 3 到达，窗口 `[3, 3, 3]` 中物品 3 出现三次，超过限制，因此该物品必须被丢弃。
- 第 6 天，物品 4 到达，窗口 `[3, 4]` 是可以的。

第 5 天的物品 3 被丢弃，这是最少必须丢弃的数量，因此返回 1。



## 思路

先说说我自己的想法吧

依旧是`unmap`记录，但是**丢弃**的情况要多考虑考虑

丢弃可以相当于`arrivals[i] = 0`

**右端口**会执行置零，只有**左端口**考虑零处，没什么影响

代码如下：

~~~c++
class Solution {
public:
    int minArrivalsToDiscard(vector<int>& arrivals, int w, int m) {
        unordered_map<int, int> ma;
        int ans = 0;
        for(int i = 0; i<arrivals.size(); i++){
            int l = i - w + 1;
            if(ma[arrivals[i]] <= m-1){
                ma[arrivals[i]]++;
            }
            else{
                arrivals[i] = 0;
                ans++;
            }
            if(l >= 0){
                ma[arrivals[l]]--;
            }
        }
        return ans;
    }
};
~~~
