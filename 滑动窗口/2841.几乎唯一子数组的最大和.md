# [2841.几乎唯一子数组的最大和](https://leetcode.cn/problems/maximum-sum-of-almost-unique-subarray/)

## 题目

给你一个整数数组 `nums` 和两个正整数 `m` 和 `k` 。

请你返回 `nums` 中长度为 `k` 的 **几乎唯一** 子数组的 **最大和** ，如果不存在几乎唯一子数组，请你返回 `0` 。

如果 `nums` 的一个子数组有至少 `m` 个互不相同的元素，我们称它是 **几乎唯一** 子数组。

子数组指的是一个数组中一段连续 **非空** 的元素序列。

## 思路

题目中有两个条件：

1. **最大和**
2. **几乎唯一**

**最大和**好说，更新和的值，max即可

**几乎唯一**就需要我们得到窗口中不同元素的数目

我起初是想用`set`来储存数组的值，用`find`来查询

后来感觉有点问题，改用`multiset`了......

但是用时直接就到达了**123ms**，内存**77.5MB**......

先把我的代码放出来吧，后面进行优化

```c++
class Solution {
public:
    long long maxSum(vector<int>& nums, int m, int k) {
        long long sum = 0, ts = 0, tm = 0; //ts为和，tm为不同元素数目
        multiset<long long> a;
        for(int i = 0; i<nums.size(); i++){
            int l = i - k + 1;
            ts += nums[i];
            auto it = a.find(nums[i]);
            if(l < 0){
                a.insert(nums[i]);
                if(it == a.end()){ //没有一样的，就添加
                    tm++;
                }
                continue;
            }
            a.insert(nums[i]);
            if(it == a.end()){
                tm++;
            }
            if(tm >= m){
                sum = max(sum, ts); //符合条件，比较
            }
            ts -= nums[l];
            a.erase(a.find(nums[l]));
            if(a.find(nums[l]) == a.end()){
                tm--;
            }
        }
        return sum;
    }
};
```

> *优化*（依旧参考**灵神**）

也可以用**哈希表**(**unordered_map**)来操作（本人对map的学习还是太浅了......）

**键**是**nums**中的数，**值**为数出现的次数

下面放代码

~~~c++
class Solution {
public:
    long long maxSum(vector<int>& nums, int m, int k) {
        long long ans = 0, s = 0;
        unordered_map<int, int> cnt;
        for (int i = 0; i < nums.size(); i++) {
            // 1. 进入窗口
            s += nums[i];
            cnt[nums[i]]++; //已经创建了一个键值对

            int left = i - k + 1;
            if (left < 0) { // 窗口大小不足 k
                continue;
            }

            // 2. 更新答案
            if (cnt.size() >= m) {
                ans = max(ans, s);
            }

            // 3. 离开窗口
            int out = nums[left];
            s -= out;
            if (--cnt[out] == 0) {
                cnt.erase(out);
            }
        }

        return ans;
    }
};
~~~

#### 复杂度分析

- 时间复杂度：O(*n*)，其中 *n* 为 *nums* 的长度。
- 空间复杂度：O(*k*)。哈希表的大小不会超过窗口长度 *k*。
