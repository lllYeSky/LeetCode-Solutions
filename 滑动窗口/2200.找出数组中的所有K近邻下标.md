# [2200.找出数组中的所有K近邻下标](https://leetcode.cn/problems/find-all-k-distant-indices-in-an-array/description/)

## 题目

给你一个下标从 **0** 开始的整数数组 `nums` 和两个整数 `key` 和 `k` 。**K 近邻下标** 是 `nums` 中的一个下标 `i` ，并满足至少存在一个下标 `j` 使得 `|i - j| <= k` 且 `nums[j] == key` 。

以列表形式返回按 **递增顺序** 排序的所有 K 近邻下标。



## 思路

要做出来很简单，我是直接暴力姐了（我当时怎么笨成这样啊

一个`set`记录符合`nums[j] == key`的下标，一个`set`记录每个下标 `+` 和 `-` 值`k`的所有值

果不其然，用时**259ms**，内存**16.7MB**

> *灵神*给了两种*O(n)*的解法，来看看吧

### 方法一：记录 key 最后一次出现的位置

对于每个`i`，考虑长度至多为 **2k+1** 的**滑动窗口**

然后统计窗口中`key`的次数，大于`0`就记录`i`

更简单的做法是，记录`key`最后一次出现的位置`last`，只要`last`在窗口中，就把`i`加入答案。

~~~c++
class Solution {
public:
    vector<int> findKDistantIndices(vector<int>& nums, int key, int k) {
        int last = -k - 1; // 保证 key 不存在时 last < i-k（不在窗口中）
        for (int i = k - 1; i >= 0; i--) {
            if (nums[i] == key) {
                last = i;
                break;
            }
        }

        vector<int> ans;
        for (int i = 0; i < nums.size(); i++) {
            if (i + k < nums.size() && nums[i + k] == key) {
                last = i + k;
            }
            if (last >= i - k) { // key 在窗口中
                ans.push_back(i);
            }
        }
        return ans;
    }
};

~~~

#### 复杂度分析

- 时间复杂度：O(*n*)，其中 *n* 是 *nums* 的长度。
- 空间复杂度：O(1)。返回值不计入。

### 方法二：同向双指针

枚举`nums`，把符合的`i`左右`k`的所有下标加入答案中

你可能会担心，如果有两个`i`的左右`k`中有重合部分怎么办？

我们可以用一个`j`来维护未加入答案的最小下标（即每次更新答案后`j`移动到**右端口+1**）

~~~c++
class Solution {
public:
    vector<int> findKDistantIndices(vector<int>& nums, int key, int k) {
        vector<int> ans;
        int n = nums.size(), j = 0;
        for (int i = 0; i < n; i++) {
            if (nums[i] != key) {
                continue;
            }
            j = max(j, i - k); // j 至少是 i-k
            while (j <= min(i + k, n - 1)) { // j 至多是 i+k，但不能越界
                ans.push_back(j++); //注意此时j的值！
            }
        }
        return ans;
    }
};

~~~

#### 复杂度分析

- 时间复杂度：O(*n*)，其中 *n* 是 *nums* 的长度。虽然写了个二重循环，但是内层循环中对 *j* 加一的总执行次数不会超过 *n* 次，所以总的时间复杂度为 O(*n*)。
- 空间复杂度：O(1)。返回值不计入。
