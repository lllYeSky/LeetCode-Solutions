# [1016.子串能表示从1到N数字的二进制串](https://leetcode.cn/problems/binary-string-with-substrings-representing-1-to-n/solutions/2265097/san-chong-suan-fa-cong-bao-li-dao-you-hu-nmtq/)

## 题目

给定一个二进制字符串 `s` 和一个正整数 `n`，如果对于 `[1, n]` 范围内的每个整数，*其二进制表示都是 `s` 的 **子字符串** ，就返回 `true`，否则返回 `false`* 。

**子字符串** 是字符串中连续的字符序列。

### 直接暴力数改二进制字符

从小到大枚举 `[1,n]` 内的数，转成二进制字符串，判断是否都在 `s` 中。一旦枚举到不在 `s` 中的数，就立刻返回 `false`。如果都在 `s` 中就返回 `true`。

~~~c++
class Solution {
public:
    bool queryString(string s, int n) {
        for (int i = 1; i <= n; i++) {
            auto bin = bitset<32>(i).to_string(); // 32位i变为string
            bin = bin.substr(bin.find('1')); // 去除前置0
            if (s.find(bin) == string::npos) // 没有就false
                return false;
        }
        return true;
    }
};

~~~

#### 复杂度分析

- 时间复杂度：O(min(*m*,*n*)⋅*m*logmin(*m*,*n*))，其中 *m* 为 *s* 的长度。
- 空间复杂度：O(log*n*)。把数字转成二进制数需要 O(log*n*) 的空间。

### 直接暴力二进制字符改数

我的思路与其有点**相似**，但可以优化

设当前得到的二进制数为 `x`，且下一个字符 `s[j+1]` 为 `c`，那么将 `x` 更新为 `(x << 1) | (c - '0')`，从而 `O(1)` 地计算出子串 `[i,j+1]` 对应的的二进制数。

此外，还可以从`s`的第一个`1`开始枚举(去掉前导`0`)

~~~c++
class Solution {
public:
    bool queryString(string s, int n) {
        unordered_set<int> seen;
        for (int i = 0, m = s.length(); i < m; ++i) {
            int x = s[i] - '0';
            if (x == 0) continue; // 二进制数从 1 开始
            for (int j = i + 1; x <= n; j++) {
                seen.insert(x);
                if (j == m) break;
                x = (x << 1) | (s[j] - '0'); // 子串 [i,j] 的二进制数
            }
        }
        return seen.size() == n;
    }
};

作者：灵茶山艾府
~~~

#### 复杂度分析

- 时间复杂度：O(*m*log*n*)，其中 *m* 为 *s* 的长度。对于固定的 *i*，内层循环的次数为 O(log*n*)，所以总的循环次数为 O(*m*log*n*)。
- 空间复杂度：O(min(*m*log*n*,*n*))，即哈希表所需要的空间。

### 巧解

先给一段**证明**

设 n 的二进制长度为 k+1，那么：

- 区间 [$2^k$,n] 内的二进制数的长度均为 k+1，这有 n−$2^k$+1 个，所以应满足 m≥k+1+(n−$2^k$+1−1)=n−$2^k$+k+1。
- 区间 [$2^{k-1}$,$2^{k}$−1] 内的二进制数的长度均为 k，这有 $2^{k-1}$ 个，所以应满足 m≥k+($2^{k-1}$−1)=$2^{k-1}$+k−1。
- 注意，当 n=1 时，k=0，此时区间 [$2^{k-1}$,$2^{k}$​−1] 不存在。直接特判这种情况，返回 s 是否包含 1

因此，如果**m<max(n−$2^{k}$+k+1,$2^{k-1}$+k−1)**，可以直接返回 `false`。

*还有*

只需要考虑长为 **k** 和 **k+1** 的这两组二进制数 `s` 是否都有，因此可以用长为 **k** 和 **k+1** 的滑动窗口实现，从而做到线性时间复杂度。

> 这是因为对于任意小于 $2^{k-1}$​ 的数 xx，它的二进制表示长度小于 k，那么它一定可以作为某个长度为 k（或 k+1）的二进制数的前缀（即子串的一部分）

进一步地，由于区间 **[$2^{k}$,n]** 内的所有数右移一位可以得到区间 **[$2^{k-1}$,⌊n/2⌋]**，所以对于 **[$2^{k-1}$,$2^{k}$​−1]**，只需从 **⌊n/2⌋+1** 开始考虑。

>这是因为所有 1 到 n 的整数，其二进制长度要么是 k，要么是 k+1，其中 k=⌊log⁡2n⌋。长度为 k 的整数范围是 [$2^{k-1}$,$2^{k}$−1]，长度为 k+1 的整数范围是 [$2^{k}$,n]。但通过滑动窗口验证时，如果字符串包含所有长度为 k+1 的二进制子串，那么它们的前缀（即去掉最低位后长度为 k 的二进制数）自然也会作为子串出现（因为子串是连续的）。因此，只需要单独检查那些不能作为更长子串前缀的长度为 k 的数，即那些大于 ⌊n/2⌋ 的数（因为 2⋅y>n 时，不存在长度为 k+1 且前缀为 y 的数）。所以检查区间为：
>
>- 长度为 k 的区间：**[⌊n/2⌋+1,$2^{k}$−1]**
>- 长度为 k+1 的区间：**[$2^{k}$,n]**
>
>这样既能覆盖所有数值，又避免了重复检查，时间复杂度为 O(m)。

~~~c++
class Solution {
public:
    bool queryString(string s, int n) {
        if (n == 1)
            return s.find('1') != string::npos;

        int m = s.length();
        int k = 31 - __builtin_clz(n); // n 的二进制长度减一
        if (m < max(n - (1 << k) + k + 1, (1 << (k - 1)) + k - 1))
            return false;

        // 对于长为 k 的在 [lower, upper] 内的二进制数，判断这些数 s 是否都有
        auto check = [&](int k, int lower, int upper) -> bool {
            if (lower > upper) return true;
            unordered_set<int> seen;
            int mask = (1 << (k - 1)) - 1;
            int x = stoi(s.substr(0, k - 1), nullptr, 2);
            for (int i = k - 1; i < m; i++) {
                // & mask 可以去掉最高比特位，从而实现滑窗的「出」
                // << 1 | (s[i] - '0') 即为滑窗的「入」
                x = ((x & mask) << 1) | (s[i] - '0');
                if (lower <= x && x <= upper)
                    seen.insert(x);
            }
            return seen.size() == upper - lower + 1;
        };

        return check(k, n / 2 + 1, (1 << k) - 1) && check(k + 1, 1 << k, n);
    }
};

~~~

#### 复杂度分析

- 时间复杂度：O(*m*)，其中 *m* 为 *s* 的长度。滑动窗口的时间复杂度为 O(*m*)。
- 空间复杂度：O(min(*m*,*n*))，即哈希表所需要的空间。
