# [3488.距离最小相等元素查询](https://leetcode.cn/problems/closest-equal-element-queries/description/)

## 题目

给你一个 **环形** 数组 `nums` 和一个数组 `queries` 。

对于每个查询 `i` ，你需要找到以下内容：

- 数组 `nums` 中下标 `queries[i]` 处的元素与 **任意** 其他下标 `j`（满足 `nums[j] == nums[queries[i]]`）之间的 **最小** 距离。如果不存在这样的下标 `j`，则该查询的结果为 `-1` 。

返回一个数组 `answer`，其大小与 `queries` 相同，其中 `answer[i]` 表示查询`i`的结果。

 

**示例 1：**

**输入：** nums = [1,3,1,4,1,3,2], queries = [0,3,5]

**输出：** [2,-1,3]

**解释：**

- 查询 0：下标 `queries[0] = 0` 处的元素为 `nums[0] = 1` 。最近的相同值下标为 2，距离为 2。
- 查询 1：下标 `queries[1] = 3` 处的元素为 `nums[3] = 4` 。不存在其他包含值 4 的下标，因此结果为 -1。
- 查询 2：下标 `queries[2] = 5` 处的元素为 `nums[5] = 3` 。最近的相同值下标为 1，距离为 3（沿着循环路径：`5 -> 6 -> 0 -> 1`）。

**示例 2：**

**输入：** nums = [1,2,3,4], queries = [0,1,2,3]

**输出：** [-1,-1,-1,-1]

**解释：**

数组 `nums` 中的每个值都是唯一的，因此没有下标与查询的元素值相同。所有查询的结果均为 -1。

 

**提示：**

- `1 <= queries.length <= nums.length <= 105`
- `1 <= nums[i] <= 106`
- `0 <= queries[i] < nums.length`

### 方法一

看示例 1，所有 1 的下标列表是 **p**=[0,2,4]。

我们在 p 中二分查找下标 i，设二分返回值为 j，那么：

- p[j−1] 就是在 i 左边的最近位置。
- p[j+1] 就是在 i 右边的最近位置。

两个距离取最小值，答案为 **min(i−p[j−1],p[j+1]−i)**

如果 j−1 或者 j+1 下标**越界**怎么办？需要写一堆 if-else 吗？

在示例 1 中，由于 nums 是循环数组：

- 在下标列表**前面**添加 4−n=−3，相当于认为在 −3 下标处也有一个 1。
- 在下标列表**末尾**添加 0+n=7，相当于认为在 7 下标处也有一个 1。

修改后的下标列表为 p=[−3,0,2,4,7]

(由于题中只要求**最近**距离，故只用在首尾加上一个下标即可)

特别地，如果 nums[i] 在 nums 中只出现了一次，那么答案为 −1。

代码实现时，可以直接把答案记录在 *queries* 数组中。

~~~c++
class Solution {
public:
    vector<int> solveQueries(vector<int>& nums, vector<int>& queries) {
        unordered_map<int, vector<int>> indices;
        for (int i = 0; i < nums.size(); i++) {
            indices[nums[i]].push_back(i);
        }

        int n = nums.size();
        for (auto& [_, p] : indices) {
            // 首尾各加一个哨兵
            int i0 = p[0];
            p.insert(p.begin(), p.back() - n);
            p.push_back(i0 + n);
        }

        for (int& i : queries) { // 注意这里是引用
            auto& p = indices[nums[i]];
            if (p.size() == 3) {
                i = -1;
            } else {
                int j = ranges::lower_bound(p, i) - p.begin(); 
                //j 对应 i 在数组里的位置
                i = min(i - p[j - 1], p[j + 1] - i);
            }
        }
        return queries;
    }
};
~~~

### 方法二

>  **预处理左右最近相同元素的下标**

我们分别在数组`nums`前后再加上`nums`，就变成了三个`nums`，其中`nums`的所有数的位置不变

定义 `left[i]` 表示在 `i` 左边的等于 `nums[i]` 的最近元素下标

我们可以像方法一那样，用 −1 表示最后一个数的下标，−2 表示倒数第二个数的下标，依此类推。

定义 `right[i]` 表示在 `i` 右边的等于 `nums[i]` 的最近元素下标

我们可以像方法一那样，用 n 表示第一个数的下标，n+1 表示第二个数的下标，依此类推。

计算方式：

- 遍历第**一二**个nums，从 **−n** 循环到 **n−1**，同时用一个哈希表记录每个数的最新位置，当 **i≥0** 时，`left[i]` 就是哈希中记录的 `nums[i]` 的位置。注意先更新 `left[i]` 再更新哈希表。
- 遍历第**三二**个nums，从 **2n−1** 循环到 **0**，同时用一个哈希表记录每个数的最新位置。当 **i<n** 时，`right[i]` 就是哈希中记录的 `nums[i]` 的位置。注意先更新 `right[i]` 再更新哈希表。

答案为：`min(i−left[i],right[i]−i)`

如果上式等于 `n`，说明只有一个 nums[i]，答案为 **−1**。

~~~c++
class Solution {
public:
    vector<int> solveQueries(vector<int>& nums, vector<int>& queries) {
        int n = nums.size();
        vector<int> left(n), right(n);
        unordered_map<int, int> pos;
        for (int i = -n; i < n; i++) {
            if (i >= 0) {
                left[i] = pos[nums[i]]; //先更新left
            }
            pos[nums[(i + n) % n]] = i;
        }

        pos.clear();
        for (int i = n * 2 - 1; i >= 0; i--) {
            if (i < n) {
                right[i] = pos[nums[i]]; // 同理
            }
            pos[nums[i % n]] = i;
        }

        for (int& i : queries) {
            int l = left[i];	
            i = i - l == n ? -1 : min(i - l, right[i] - i);
            // 用i - l是否等于n来判断是否就只有一个值
        }
        return queries;
    }
};
~~~

上面的写法并不是真正的一次遍历，因为遍历了 *nums* 两次。

要做到真正的一次遍历，需要记录每个元素首次出现的位置和最后一次出现的位置。

~~~c++
class Solution {
public:
    vector<int> solveQueries(vector<int>& nums, vector<int>& queries) {
        int n = nums.size();
        vector<int> left(n), right(n);
        unordered_map<int, int> first, last; // 记录首次出现和最后一次出现的位置
        for (int i = 0; i < n; i++) {
            int x = nums[i];
            left[i] = last.contains(x) ? last[x] : -1;
            if (left[i] >= 0) {
                right[left[i]] = i;
            }
            if (!first.contains(x)) {
                first[x] = i;
            }
            last[x] = i;
        }

        for (int& i : queries) {
            int l = left[i] >= 0 ? left[i] : last[nums[i]] - n;
            if (i - l == n) {
                i = -1;
            } else {
                int r = right[i] ? right[i] : first[nums[i]] + n;
                i = min(i - l, r - i);
            }
        }
        return queries;
    }
};
~~~

## 复杂度分析

### 方法一

- 时间复杂度：O(*n*+*q*log*n*)，其中 *n* 是 *nums* 的长度，*q* 是 *queries* 的长度。每次二分需要 O(log*n*) 的时间。
- 空间复杂度：O(*n*)。返回值不计入。

### 方法二

- 时间复杂度：O(*n*+*q*)，其中 *n* 是 *nums* 的长度，*q* 是 *queries* 的长度。
- 空间复杂度：O(*n*)。返回值不计入。
